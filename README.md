# infostil

Навык написания текстов для ИИ-агента: инфостиль и чистка невидимых знаков в конце. Самостоятельный, другие навыки не нужны.

| Файл | Что это |
|---|---|
| `SKILL.md` | Правила текста: вопрос и польза до текста, суть сверху, термины, легенды к данным, таблицы, факт отдельно от оценки, схемы, чистка знаков |
| `scripts/chistka.py` | Просмотр и удаление невидимых знаков. Нужен только Python 3 |

## Установка

```bash
git clone https://github.com/48981/infostil.git ~/.claude/skills/infostil
```

Вызывается командой `/infostil` либо сам, когда агент пишет отчёт, документ, статью или письмо.

## Чистка знаков

```bash
python scripts/chistka.py текст.md          # показать: строка · позиция · код · имя · действие · контекст
python scripts/chistka.py текст.md --fix    # удалить (оригинал останется в текст.md.bak)
```

| Что делает | Знаки |
|---|---|
| Удаляет | Нулевой ширины, управляющие направлением, невидимые операторы, BOM, мягкий перенос, теги, управляющие |
| Только показывает | Неразрывные и узкие пробелы, знаки частного использования, знаки вне базы Unicode этой версии Python |
| Не трогает | Склейки, селекторы и теги внутри эмодзи; служебные знаки арабского, иврита и индийских письменностей |

Файл должен быть в UTF-8. Переводы строк (CRLF или LF) остаются как были.

Граница: статистический водяной знак в подборе слов (OpenAI textGrain и подобные) скрипт не видит и не снимает. Он не в знаках, а в выборе слов, поэтому «знаков нет» не значит «писал человек».

Навык связан с кодексом [agent-baza](https://github.com/48981/agent-baza), но работает и без него.
